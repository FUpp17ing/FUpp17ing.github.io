# FUpp17ing.github.io
天玑谱——中国古代天文算法可视化设计 说明文档

## 作品简介
天文算法是中华自然科学中的瑰宝，本作品以数字技术激活中华天文文明基因，系统深度整合算法推演、仪器解构、人物传承、典籍活化四大维度，借助可视化界面与交互功能为用户提供深入了解中国古代天文算法智慧的平台。

## 预览链接
https://fupp17ing.github.io/

## 打开方式
1. 使用Windows系统
2. 下载项目压缩包并解压至任意路径文件夹 
3. 双击打开根目录pages中的 首页.html 
4. 在首页点击导航条即可跳转其他网站页面
